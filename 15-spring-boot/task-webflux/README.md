# Task Management API – Spring WebFlux

This project is a **reactive RESTful API** built using **Spring Boot WebFlux** and **Spring Data R2DBC** with **MySQL**.  
It demonstrates non-blocking, asynchronous CRUD operations using reactive programming.

---

## 🚀 Tech Stack
- Java 23
- Spring Boot 3.x
- Spring WebFlux
- Spring Data R2DBC
- MySQL
- Reactor (Mono / Flux)
- Netty Server

---

## ✨ Features
- Reactive REST APIs
- Non-blocking database access
- Task CRUD operations
- JSON request/response handling
- Tested using Postman
