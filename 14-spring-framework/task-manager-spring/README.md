# Task Manager – Spring Console Application

This project is a **console-based Task Management application** built using **Spring Core** with Java-based configuration.  
It focuses on understanding core Spring concepts such as dependency injection, service layers, and repository patterns.

---

## 🚀 Tech Stack
- Java
- Spring Core (Java Configuration)
- Maven
- Console-based UI

---

## ✨ Features
- Create, update, and manage tasks via console
- Layered architecture (UI, Service, Repository)
- Enum-based task status handling
- Spring Dependency Injection
